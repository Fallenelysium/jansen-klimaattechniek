# Jansen Klimaattechniek

Een simpele bedrijfswebsite voor een airco service bedrijf.

## Features
- Responsive layout met Bootstrap
- Diensten overzicht
- Offerteformulier met JavaScript validatie
- Live feedback bij invoer

## Technologie
- HTML
- CSS (Bootstrap + custom styling)
- JavaScript

## Doel
Oefenproject om frontend skills te ontwikkelen en een portfolio op te bouwen.
